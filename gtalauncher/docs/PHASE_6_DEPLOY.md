# GTAMP v1.6.0 — Phase 6 remote players

## Hook version
Must log: `==== GTAMP hook v1.6.0 PID=... ====`

## Install (small update)
Use release asset `GTAMP-v1.6.0-UPDATE.zip`:
1. Unzip
2. Copy into your launcher:
   - `gtamp_hook.dll` → `resources/native/`
   - `gtamp_injector.exe` → `resources/native/`
   - `app.asar` → `resources/` (if included)
3. Restart GTA + launcher

## Features
- Remote player ped lifecycle (join/leave/timeout)
- FiveM-style nametags `[id] name`
- Map blips, position lerp
- F8 chat
- TestBot freeroam walker
