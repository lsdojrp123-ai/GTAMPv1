Discord Rich Presence art assets for GTAMP
==========================================

Upload these on:
  https://discord.com/developers/applications
  → your GTAMP app → Rich Presence → Art Assets

Files (name must match exactly when uploading):
  gtamp.png  → asset name: gtamp   (large image)
  gta5.png   → asset name: gta5    (small image)

Then paste Application ID into GTAMP Settings → Discord.
