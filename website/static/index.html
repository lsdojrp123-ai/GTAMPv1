FAQ

Common questions.

What is GTAMP?
A FiveM-style multiplayer launcher for GTA V, built entirely with our own code.
Is it FiveM?
No. GTAMP is inspired by FiveM's architecture but is its own codebase.
Do I need the Rockstar Launcher?
Yes — GTA must be started through the platform it was bought from (Steam, Rockstar, or Epic).
How do I run my own server?
Click "Create your own server", install the artifacts, and follow the docs.
