F.A.Q.

Will I get banned from GTA Online for playing GTAMP?
No, GTAMP does not interact with Rockstar Games Online Services other than to validate your game copy the first time you launch it.
Is GTAMP the same as FiveM?
No. GTAMP is inspired by FiveM's architecture but is an entirely separate, own codebase.
Can I run my own server?
Yes. Click "Create a server now", install the artifacts, and follow the docs.
I want to run a server, how can I do so?
Refer to our server page to get started. Our community is there to help.
