F.A.Q.

# Will I get banned from GTA Online for playing GTAMP?

No. GTAMP does not interact with Rockstar Games Online Services, and it doesn't modify your game files at all, so you don't have to do anything to switch between GTAMP and GTA Online.

# Is GTAMP the same project as FiveM?

No. GTAMP is our own codebase, built independently. It follows a similar architecture philosophy — a client hook, a relay server, and community servers — but shares no code with any other project.

# Can I play GTAMP on my console?

Unfortunately not. GTAMP relies on mechanisms that only exist on the PC platform, so a PC copy of Grand Theft Auto V is required.

# How many players can a server hold?

Our relay is built to scale with the server host's bandwidth. Small community servers typically run 8–32 players; larger capsules are on the roadmap as sync quality improves.

# My GTAMP crashes, what should I do?

You should post a topic on the forum describing what happened, using as much detail as you can — the more you tell us, the faster we can fix it.

# What does the M in GTAMP stand for?

Multiplayer — GTAMP is the GTA Multiplayer Project: a modification that adds community-run multiplayer to Grand Theft Auto V.

# I want to run a server, how do I do so?

Running your own server is easy. Refer to our server page to get started, and check the documentation for configuration details.

You can also ask the community on our forum — someone is always happy to help.
